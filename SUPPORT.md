# Obtenir de l'aide

## Avant de demander

1. Lisez le README du dépôt concerné : installation, usage, limites connues.
2. Cherchez dans les issues ouvertes et fermées : la réponse existe peut-être déjà.

## Poser une question

Ouvrez une issue avec le modèle **❓ Question ou demande d'aide** sur le dépôt concerné.
Précisez ce que vous essayez de faire, ce que vous avez déjà tenté et la version utilisée.

## Signaler un bug ou proposer une amélioration

Utilisez les modèles **🐛 Rapport de bug** et **✨ Proposition de fonctionnalité** du
dépôt concerné. Le guide [CONTRIBUTING.md](CONTRIBUTING.md) décrit ce qui est attendu.

## Sécurité

Une vulnérabilité ne se signale jamais dans une issue publique : suivez
[SECURITY.md](SECURITY.md).

## Support commercial

Les outils de Kanibal Studio sont publiés « en l'état », sans engagement de délai de
réponse. Les clients d'Altavista360 disposent de leurs canaux de support habituels via
[altavista360.com](https://altavista360.com) ; GitHub n'en fait pas partie.
